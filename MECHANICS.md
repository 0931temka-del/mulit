# Как сделан ролик «Последний звонок» (механика)

Простыми словами: ролик собирается как конвейер из пяти шагов. Нейросети (платные) нужны только для голоса и музыки. Картинка в первой версии рисуется **кодом**, бесплатно.

## Схема

```
script/narration.md          текст рассказчика (5 сцен)
        |
        v
tools_tts.py  ───────────►  audio/narr_1..5.mp3 + narr_N.json   (озвучка + время каждой буквы)
tools_music.py / tools_sfx.py ► audio/music_*.mp3, sfx_*.mp3     (музыка и звуки)
        |
        v
build_timeline.py  ───────►  web/timeline.json   (кто, когда и что говорит; субтитры; гудки)
build_audio.py     ───────►  audio/mix.wav       (весь звук смикширован ffmpeg)
        |
        v
web/index.html + web/main.js (3D-сцена на three.js)   читает timeline.json
render.mjs  ──────────────►  кадры .jpg (24 в секунду, скриншоты сцены)
        |
        v
ffmpeg  ──────────────────►  готовое видео (кадры + mix.wav)
```

## Что за что отвечает

| Шаг | Файл | Чем делается | Платно? |
|---|---|---|---|
| Текст | `script/narration.md` | написан вручную (Claude) | нет |
| Голос рассказчика | `tools_tts.py` | ElevenLabs API (`text-to-speech/with-timestamps`), русский язык. Сервис возвращает ещё время каждой буквы, по нему синхронизируются субтитры и губы | да, ключ ElevenLabs |
| Музыка и звуки | `tools_music.py`, `tools_sfx.py` | ElevenLabs `sound-generation` (пианино, гудки, ветер, калитка...) | да, ElevenLabs |
| Расписание | `build_timeline.py` | Python: читает время букв и строит `timeline.json` (субтитры, реплики бабушки и соседки для движения рта, гудки) | нет |
| Микс звука | `build_audio.py` | Python + `ffmpeg`: голос, звуки, синтезированные гудки, музыка с «приглушением» под голос | нет |
| Картинка | `web/main.js`, `web/index.html` | **three.js** (3D в браузере). Персонажи, дом, комната, окно с городом, телефон собраны из простых фигур кодом (шары, кубы, цилиндры), есть свет, анимация и мимика | нет |
| Съёмка кадров | `render.mjs` | **playwright-core** + Chromium без экрана: открывает сцену, перематывает на кадр N, делает скриншот. Параллельно 4 процесса | нет |
| Сборка | `ffmpeg` | склеивает кадры в видео и добавляет `mix.wav` | нет |

## Что использовано

- **three.js 0.160** — 3D-движок (npm-пакет `three`).
- **playwright-core** — управление Chromium (npm), браузер лежит в `/opt/pw-browsers/chromium`.
- **ffmpeg** — склейка видео и работа со звуком.
- **Python 3 + Node.js** — все скрипты.
- **ElevenLabs API** — голос, музыка, звуки. Ключ `ELEVENLABS_API_KEY` в окружении.
- Никаких внешних репозиториев и никаких специальных «скиллов» Claude для видео не использовалось: всё это обычные скрипты в этом репозитории.

## Версия с реальными кадрами (тест)

Отдельная ветка идеи: вместо 3D-сцены кадры рисует Gemini.

- `gen_images.py` — запросы к Gemini (`gemini-2.5-flash-image`) → `frames_ai/01..06.png`.
- `assemble_test.py` — `ffmpeg`: Ken Burns (плавное приближение) по фото + готовая озвучка + музыка → `out/test_ai.mp4`, 9:16.

## Как запустить бесплатную 3D-версию

```
python3 -m http.server 8123 &                      # сервер для сцены
node render.mjs all out/frames 4 0                 # (и для 1,2,3) кадры
ffmpeg -framerate 24 -i out/frames/%05d.jpg -i audio/mix.wav ... out.mp4
```
`MAXT=29.4 node render.mjs ...` — отрендерить только первые 29.4 секунды.
